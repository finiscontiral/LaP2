# LaP2

**English** | [日本語](./docs/jp/README.md)

LaP2 stands for `La plus program`.

## Goals
Our goal is to create a library and application that serves as an entry point for beginners to develop an interest and curiosity in satellite orbits. 
At the same time, we aim to ensure the API remains clean and concise while achieving mission-grade accuracy so that it can be genuinely useful in real-world scenarios.

Initially, it will start as a wrapper around multiple existing libraries, but the ultimate goal is to implement everything from scratch based on fundamental orbital mechanics theory. Contributions and support are always welcome!
